Hospital Readmission Prediction\n
Overview\n
This project predicts whether a patient will be readmitted to the hospital within 30 days using the Diabetes 130-US Hospitals dataset.\n

Dataset\n
Diabetes 130-US Hospitals for Years 1999–2008.\n

The original dataset is not included in this repository.\n

Objective\n
To develop a machine learning classification model for predicting 30-day hospital readmission.\n

Model\n
Logistic Regression with L2 Regularization\n
Evaluation Metrics\n
ROC-AUC\n
Precision\n
Recall\n
F1 Score\n
ROC Curve\n
Project Files\n
Hospital_Readmission_Prediction.ipynb — Complete analysis and model\n
